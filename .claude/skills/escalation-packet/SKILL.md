# The escalation packet

This is the product. Everything else exists to produce it.

**Design target:** an executive decides in under 90 seconds without listening to the recording.

## Required sections

| Section | Rule |
|---|---|
| Header | Reference, language, channel, duration, consent status, band — visible without scrolling |
| Assessment | SVI with the nine-dimension breakdown, aggregate confidence, overrides applied. Never a bare number |
| Alerts | Type, severity, and the exact utterance that triggered each. Sorted to the top, require acknowledgement |
| Structured case | Incident, timeline, persons, threats, safety now, medical, legal status, isolation, stated request — every field links to its source utterance |
| Full transcript | Both sides, timestamped, original language. Assistant turns visually distinct — the executive must be able to audit what the AI said |
| Evidence | Clicking any dimension highlights the utterances behind it. No assessment without traceable evidence |
| Trajectory | How the SVI moved and which utterance moved it |
| Recommendations | Each with rationale and policy citation. Rendered as awaiting decision, never as action taken |
| Uncertainty | ASR confidence, audio quality, language confidence, model agreement — or a prominent "Needs Human Assessment" instead of a score. Equal prominence to the score, never a footnote |
| Decision area | Confirm / modify / reject per recommendation, band override with a mandatory written reason, take-over button |

On the screen itself: *"This assessment is an assistive prioritisation aid generated by an AI system. It is not a clinical, legal or forensic determination. All decisions rest with the reviewing officer."*

## Decision and audit rules

- AI output and human decisions live in **separate tables** (`decisions_ai`, `decisions_human`). The record must never read as though a machine decided.
- Every AI output displayed to an executive is logged as displayed, with a timestamp.
- Every decision is logged with officer, time and rationale.
- Overriding a Critical band downward requires a written reason — not to police the officer, but to make the disagreement visible and auditable.
- Nobody, including a supervisor, can delete an audit entry.

## Victim timeline

Stages: request received → under review → officer assigned → action taken → follow-up scheduled → closed/continuing.

- It **never** shows the SVI, band, dimensions, emotions or alerts. Enforced server-side by role.
- It **never** shows anything the executive has not confirmed. A recommendation is not an action.
- Plain, specific, non-clinical language: "a counsellor will call you", not "counselling pathway initiated".
- An "add information" control appends to the existing case rather than starting a new session. This is the concrete implementation of the never-repeat-your-story promise.
