## What this directory owns

The console where a helpline executive reads the AI's work and **makes every decision**: queue, case packet, evidence, alerts, recommendations, trajectory, takeover, supervisor view, audit viewer.

## Design intent

An executive must decide in under 90 seconds without listening to the recording. This is a government tool used under pressure by tired people. Sober, dense, legible. No gradients, no decorative animation, no emoji.

## Layout

```
src/api/            REST client + typed WebSocket client
src/types/          contracts.ts — mirrors docs/contracts/CONTRACTS.md
src/pages/          Login · Queue · Case · Supervisor · Audit

                      DimensionBreakdown · EvidencePanel · AlertBanner ·
                      RecommendationCard · TrajectoryChart · SafeSignalCard ·
                      NeedsHumanState · TakeoverButton

```

**Build every component against `src/mocks/` first.** Team C must never be blocked waiting on Team B.

## Phases

**P0 — Day 1** — Vite + React + TS + Tailwind scaffold, routing, WebSocket client stub talking to the backend echo.

**P1 — Days 2–4** — login; queue on mock data (ranked by band and alerts, language, wait time, alert badges, privacy-safe previews); three-region case layout on mock data; two-sided transcript component with span highlighting.

**P2 — Days 5–8 → Day 8 gate** — real events wired; structured record with evidence links; SVI gauge and dimension breakdown; confidence chips; alerts with acknowledgement; recommendation cards with confirm / modify / reject writing to the audit log; band override with mandatory reason; takeover button.

**P3 — Days 9–11** — trajectory chart with clickable change-evidence; SAFE-SIGNAL and coercion cards; "Needs Human Assessment" state; supervisor view; audit viewer; case export UI; deck visuals.

**P4 — Days 12–13** — freeze, demo theming, rehearsal-driven fixes only.

## Rules

- The SVI is **never** a bare number — the dimension breakdown is adjacent and confidence has equal prominence.
- Every assessment field links to the utterance that produced it. No assessment without traceable evidence.
- Recommendations render as **awaiting decision**, never as action taken.
- Assistant turns and victim turns are visually distinct — the executive must be able to audit what the AI said.
- Alerts sort to the top and require acknowledgement.
- "Needs Human Assessment" is a designed state, not an error state.
- The screen carries: *"This assessment is an assistive prioritisation aid generated by an AI system. It is not a clinical, legal or forensic determination. All decisions rest with the reviewing officer."* Judges photograph screens.
