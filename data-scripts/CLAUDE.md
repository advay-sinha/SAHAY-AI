# Data Scripts Team Instructions

Read root `CLAUDE.md`, the dataset governance skill, dataset/service plan and external decision log.

This directory contains manifests, registries, labelling tools, preprocessing code and aggregate evaluation results. Raw/processed audio, model weights and datasets live under external `DATA_ROOT`, never in Git.

Do not download or generate an external corpus without exact approval. Never use real victim or NHAA data. Preserve raw inputs, verify checksums, split by speaker and keep the final scenario test set locked. Record source, version, licence, purpose and limitations. High-consequence labels require two annotators and adjudication.
