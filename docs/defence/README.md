# Judge defence (plan M16)

| Page | What it is | How it is made |
|---|---|---|
| `NUMBERS.md` | Headline numbers per language, each with its evidence class | Generated by `ml.eval.defence` |
| `RED_TEAM.md` | Red-team result by language, category and severity | Generated by `ml.eval.defence` |
| `LIMITATIONS.md` | What the evidence does not support | Written; checked by the wording guard |
| `JUDGE_QA.md` | Short answers to likely questions, with pointers | Written; checked by the wording guard |

Component cards:

| Component | Card |
|---|---|
| Crisis pre-check and detectors | `ml/nlp/DETECTORS_CARD.md` |
| SVI engine (provisional weights) | `ml/svi/SVI_CARD.md` |
| Output validator | `ml/guardrails/VALIDATOR_CARD.md` |
| Speech-to-text | `ml/voice/ASR_CARD.md` |
| Voice output | `ml/tts/TTS_CARD.md` |
| D4 voice distress | `ml/acoustics/D4_CARD.md` |
| Speech emotion (shadow) | `ml/ser/MODEL_CARD.md` |
| Text affect (shadow) | `ml/textaffect/MODEL_CARD.md` |
| Shadow classifiers | `ml/shadow/MODEL_CARD.md`, `ml/training/STAGE_W_CARD.md` |

Regenerate after any new evaluation:

```text
python -m ml.eval.run_eval --out ml/eval/results --tag <date>
python -m ml.eval.table --eval-json ml/eval/results/eval-<date>.json --latency-json ml/eval/results/latency-<date>.json --training-root <SAHAY_TRAINING_ROOT> --out ml/eval/results --tag eval-table-<date>
python -m ml.eval.defence --eval-json ml/eval/results/eval-<date>.json --table-json ml/eval/results/eval-table-<date>.json --out docs/defence
```

`ml/tests/test_defence.py` checks that every card and page here passes the wording guard.
